01 · 先认旅店元素

数字是房客需求，边界是你的判断

每个数字格是一位房客。金色圆角房框表示两格确定同住；交叉封条表示这两格绝不配成一间。

  • 房框与封条都不会盖住数字
  • 最多同时高亮两种需求

02 · 再学怎么落笔

直接点接缝，或依次选择正交相邻两格

确定新客房会自动拆掉与它重叠的旧房，并清除这两位房客周围的全部排除线；这一整组变化只算一步，也可一次撤销。

  • 再次确定同一房间会拆房
  • 入住后的房客旁不能再画排除线

03 · 最后看通关条件

铺满全馆，而且完整组合各用一次

每格必须恰好属于一间房；从 0 到本馆最大需求的所有无序数对（含 0·0 这类同数对）必须各出现一次。

  • 重复组合会显示三角冲突印
  • 排除线只是笔记，不参与胜负

DOMINOSA · RULES & ORIGIN

掌柜的完整排房守则

  1. 一

    完整组合，一种一次最大数字为 N 时，必须使用 0 ≤ a ≤ b ≤ N 的每一种无序数对，包含所有同数对，且每种恰好一间。

  2. 二

    每格恰好入住一次客房只能覆盖上下左右正交相邻的两格；对角、跨边和重叠都不合法。最终所有格必须完全铺满。

  3. 三

    确定与排除含义相反金框表示两格确定同房；交叉封条表示两格确定不同房。排除线只是推理笔记，不参与最终通关判定。

严格保留的操作语义

再次操作已确定房间会拆除它。放置新房时，与两端重叠的一或两间旧房会先拆除，两端周围的所有排除线也会清掉。只有两端都尚未入住时，才可切换排除线。

相同数字组合允许暂时重复，所有重复房间都会出现红色三角冲突印；引擎不会替你悄悄拒绝这一步，但重复状态不能通关。数字追踪最多同时选择两种。

规模与唯一解选项

阶数 N 的旅店严格为 (N+2) × (N+1)，共 (N+1)(N+2)/2 间房；每个数字在题面恰出现 N+2 次。三档分别是 N=3、4、5。

“确保唯一解”开启时，题面必须由 exact-cover 求解器完整排除第二解后才会展示唯一印。关闭时仍由构造见证与求解器验证至少一解，但只标注“不保证唯一”；若恰好唯一，会如实显示。

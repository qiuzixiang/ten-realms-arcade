## 规则真值

棋盘由障碍 `#`、空栖位 `.` 和纸鹤 `P` 构成。一步合法动作必须同时满足：

1. 起点有纸鹤；
2. 终点与起点在同一行或同一列，距离恰好两格；
3. 中间相邻格有另一只纸鹤；
4. 终点是可用的空栖位；
5. 对角、跨越障碍、跨越空位或落到占用栖位均为原子无效操作。

动作完成后，起点与中间格变为空栖位，终点变为纸鹤。每一步恰好令纸鹤总数减少一。任意位置只剩一只纸鹤即胜；不要求最后一只位于中心或特定终点。死局不是独立失败结算，玩家可撤销或重开。

## 不得作出的声明

- 不宣称解法唯一；同一题可能有多条合法归巢顺序。
- 不设置“最少步数”或“建议步数”：初始有 `N` 只纸鹤的任何通关都必为 `N−1` 步。
- 最后落点收藏只能作为额外图鉴，不得变成胜利条件。

## 固定题面与证明

六关分三档，每关由单鹤完成状态反向施加合法跳跃得到，并保留可正向回放的 `solution` 见证。测试还会从初始状态运行不读取见证的 DFS，确认至少存在一条到单鹤状态的路径。发布题只承诺“已验证可解”，不承诺唯一。

教程固定使用 `dawn-perch-101`：初始 8 鹤；真实操作 `3,0>3,2` 后剩 7 鹤；回放七步见证后任意位置剩 1 鹤，规则引擎判定完成。三张 SVG 均带 `data-level-id`、`data-state` 与动作/计数标记。

## 主题映射

| 规则概念 | 世界元素 | 视觉与操作 | 不得改变的含义 |
| --- | --- | --- | --- |
| 棋子 | 立体纸鹤 | 有翼形轮廓，点按选中 | 每次只能移动一只 |
| 空孔 | 发光栖位 | 圆形落点 | 只有空栖位可落下 |
| 被跨棋子 | 同伴纸鹤 | 跳跃轨迹经过 | 落地时恰好移除这一只 |

| 剩一枚 | 最后一只归巢鹤 | 月门亮起 | 所在位置不限 |

## 存档与完成事件

- 私有前缀：`ten-realms-v2:games:paper-crane-sanctuary:`；教程版本 `v1`。
- 存档只保存合法动作序列，恢复时从固定题面逐步重放，不能用伪造棋盘或完成布尔值领取奖励。
- `runId` 每次新开/重开均稳定生成；`eventId = paper-crane-sanctuary:{runId}:complete`。
- 完成 payload 固化从官方题面实际执行的规范 `timeline`；创建、outbox 恢复和投递前都重新逐步回放，并核对单鹤完成、题面 seed、真实固定步数及稳定 run/event ID。缺失时间线、伪造步数或不能真实归巢的 pending 会被丢弃。
- 完成 payload 必须先成功写入本地 records、未交付 session 标记与 `outbox:v1`，才允许调用 `RealmArcade.complete`；其中任何一次写入失败都保持 fail-closed，内存兼容队列也不算宿主确认。宿主同步接收成功后再移除 outbox，失败时按 `eventId` 原样重试；页面启动和两种 realm-ready 事件都会用同一完成时间与 event ID 补齐部分写并重试。
- 通关后撤销会清除冻结 completion、恢复计时并生成新的 run ID；重新归巢使用新的稳定事件结算，不复用已经发放的完成编号。

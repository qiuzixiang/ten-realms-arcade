RULES / SOURCE

越过一鹤，落向空栖位

  1. 01起点与中间位置都必须有纸鹤；终点必须是紧接着的空栖位。
  2. 02只能水平或垂直跳两格。对角、远跳、跨空位和障碍都无效。
  3. 03落地后，起点与被跨纸鹤同时离开；庭中纸鹤恰好减少一只。
  4. 04任意位置只剩一只纸鹤即通关，不要求最后停在中心。

规则参考 Simon Tatham’s Portable Puzzle Collection 的 Pegs 与 ebnbin/puzzles 中文规则，依据 MIT License 独立重新实现。固定来源见本游戏 RULES.md。

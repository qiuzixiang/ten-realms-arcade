CORE SAFETY PROTOCOL / SLANT

熔心安全规程

每格一块导流板，整网不成环

  1. 01

    每格恰好一块

    通关时，每个舱格必须是 \ 或 /，不能留空。

  2. 02

    数字必须精确

    数字交点周围，以该点为端点的导流板数量必须恰好相等。多一块、少一块都不行。

  3. 03

    任何闭环都禁止

    导流板可以连成树枝状管网，但不得首尾相接形成任何尺寸的封闭热环。

  4. 04

    缺数字不是 0

    没有压力数字的交点不限制端接数，但仍受全局无环条件约束。

  5. 05

    正反向都能循环

    点按为空→\→/→空；右键顺序相反。键盘也可直接输入方向或退格清空。

  6. 06

    三项同时成立才通关

    全部填满、所有数字精确、全局没有闭环，缺一都不会结算。

六个发布题均由独立求解器搜索到第二解，证明未截断且解数恰为 1。固定来源与证明契约见本游戏 RULES.md。

    PROTOCOL / MAGNETS

    低温实验规程

    三种模块，一套完整磁场

    1. 01

      槽位配对固定

      每个可操作格恰好属于一个横向或纵向双格槽位。配对方向不能改变；奇数题盘可能有一个永久中性的封闭空位。

    2. 02

      整槽只有三种完成状态

      装入“+−”“−+”之一，或装入两端都中性的模块。未填与明确中性不同，不能只填一端。

    3. 03

      四周分别统计正负极

      顶部统计每列正极，底部统计每列负极，左侧统计每行正极，右侧统计每行负极。数字 0 是真实线索，破折号才表示缺失且不约束。

    4. 04

      同性不能正交相邻

      两个正极或两个负极不能上下左右接触；对角相邻允许，异性相邻允许，中性模块可接触任何极性。

    5. 05

      候选与标灰只是笔记

      两个问号表示“这里不可能中性”；线索也可点按标灰。两类笔记都不计数、不填槽、不改变冲突与胜利。

    6. 06

      全部条件同时成立才完成

      每个槽位已明确装载、所有已给正负线索精确相等、没有任何同性正交接触，三项缺一不可。

    原作循环与本作输入

    点按空槽某一端或按 Enter：该端“+ → − → 清空”，另一端同步相反。中性模块须先用 Space 或中性工具转为候选再清空；磁铁上 Space 不生效。右键、长按或 Space：未填 → 中性 → 两个问号 → 未填。

    方向键 / WASD 移动，Q 切换候选，Delete 清空，Ctrl/⌘+Z 撤销，R 重开，N 换题，M 静音，? 打开规则。任一模态窗口打开时，棋盘快捷键都会隔离。

    规则源流：Janko “Magnete” → James Harvey / Simon Tatham’s Portable Puzzle Collection → ebnbin/puzzles 中文网页版本。本作规则引擎与界面为独立重新实现，并保留上游 MIT 致谢。

# 十境谜游馆 2.0 · 导览封面 ImageGen 记录

生成模式：Codex 内置 ImageGen（`stylized-concept`），每款游戏单独生成一次。  
成品规格：`1200 × 652` WebP，网页以 `object-fit: cover` 展示。  
共同要求：宣传主视觉而非棋盘截图；中央主体清晰；右下角为网页 `REALM` 编号留空；不生成标题、Logo、水印、教程图、棋盘或 HUD。

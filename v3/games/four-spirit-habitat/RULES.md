# 四灵栖境署：规则契约

本游戏以 Simon Tatham Portable Puzzle Collection 的 **Map** 为规则原型。参考快照为 `ebnbin/puzzles@5a9e1795a3324e0f6433b79fbe31cbd9b12048a3`：`doc-zh/map.html`、`src/games/map.ts` 与 `vendor/sgtpuzzles/map.c`。上游代码按 MIT License 发布；署名随 V3.0 第三方声明保留。

## 不变量

1. 棋盘由正交连通的不规则区域组成，每个区域最终恰有四灵之一。
2. 只有共享一段边界的区域相邻；仅在一点或对角接触不相邻。
3. 任意相邻区域不得使用同一种守护灵。
4. 固定神龛颜色属于题面，不可清除或改写。
5. 候选印只作笔记，不参与冲突或完成判定；正式着色会清掉该区域候选。
6. 胜利要求全部区域正式着色且零相邻冲突。信息不足但无冲突仍是未完成。
7. 六个发布题由固定布局、线索与 seed 复现；独立图着色回溯器不读取内置答案，并搜索到第二解证明每题唯一。

## 主题映射

四种颜色分别映射为水麟、火羽、月狐与森龟，并同时使用色彩、字形与纹理区分。地图区域是灵兽栖境，共享边界表示生态接壤；只在角点相触不构成接壤。主题、候选印、动画与奖励不改变相邻图着色规则。

## 教程真值

三张教程固定使用 `spirit-spring`：初始神龛状态；为区域 1 安置森龟的一次合法操作；完整解 `0,3,1,0,2,0,3,3,2`。测试会从 `levels.mjs` 和规则引擎复算三态。

## 存档与完成

本游戏只使用 `ten-realms-v3:games:four-spirit-habitat:` 前缀。会话为每次正式安置或清除保存 `timeline`；恢复时从官方初始题面逐步重放，核对关卡、固定神龛、最终颜色与步数，候选印仍不进入胜负证明。完成 payload 固化同一时间线并再次要求“全部正式着色且零冲突”，初始盘、截短时间线和伪步数都不能结算。每局使用稳定 `runId`，完成事件为 `four-spirit-habitat:<runId>:complete`；先进入私有 outbox，只有宿主完成 API 成功返回后才移除，兼容队列不冒充确认。

# 瓷流工坊 · 冻结规则 v1

规则为 Slant / Gokigen Naname；坐标从左上开始，格索引 `y*width+x`，交点索引 `y*(width+1)+x`。每格恰好放一片 `\`（左上—右下）或 `/`（右上—左下）。每个有数字的交点统计接入此点的斜片端头数量，角/边/内部上限为 1/2/4。`null` 是无数字，不是 0。

全格填满、全部数字恰好、整个无向图没有任何闭环，三条同时满足才合格。多个分离的树状分支完全合法，没有入口、出口、流速或必须全盘相连的规则。过程允许暂时冲突；不惩罚、不自动改格。局部数字当前吻合且周围仍有空格，不能标为稳定锁定。

默认先选 `\`、`/`、清除工具，然后点格中央直接设置；同态、越界、非法值为 no-op。检查模式下点格只改变选中格，再用四个 ≥48px 按钮查看节点。铅笔笔记为独立虚线，不进计数或判胜。可选循环模式清楚标记“空→╲→╱→空”，右键反向；选择方向工具会退出循环，键盘始终直接输入。手指移动超过 8px 取消点按。点交点圆章附近时只选中格并进入检查模式，不安装，避免数字与格的重叠误触。

方向键选格，`\`、`/`、退格直接输入；Ctrl/⌘ Z 撤销，Shift+Ctrl/⌘ Z 重做。撤销/重做恢复正式动作和笔记；界面操作数为当前历史前缀中的实际正式变更次数，不声明最少步。重开清空本局，已经认证的首通与独立检验留存。

提示三层：定位值得看的点/路径→依据当前计数上下界或已有连接解释→另次明确确认安装一片。不会读取内置解来决定方向。当前冲突必须先修；所有数字线索和无环约束都由引擎计算。提示标记“提示完成”，不扣已完成关数。全文解释与高亮包含已连通的完整路径。

六章每章十关。第一章 4×4，第二章 4×4/5×5，第三章 5×5，第四章 5×5/6×6，第五章 6×6，第六章 6×6/6×7。所有关卡可直接练习，无关卡锁。60 关均通过独立唯一搜索。第三至第六章的题不靠单独局部计数完成；第五、六章要求至少一处 ≥6 边且横跨半盘的路径排除。章节不是逐关严格单调的难度排名。没有测试过玩家平均时长，故不宣称 5–12 分钟。

`oracle.mjs` 不引用主引擎；用自己的端点坐标、邻接 DFS 判环和二值完备搜索，只读取题面而不读取内置答案。唯一性必须 `count=1, truncated=false, exhausted=true`，每题证书位于 `release/certificates.json`。认证的强制推理轨迹仅用于生成与证明；运行提示重新计算当前状态。

会话保存动作历史、cursor、稳定 runId、levelId、seed、生成器/规则版本与累计提示数。私有前缀 `mini-polish:porcelain-flow-atelier:v1:`；教程已读键另存，不影响进度。恢复重放完整历史并校验；记录和 outbox 必须附带经规则复算的真实完成动作证明，不信任完成布尔值。奖励 ID 是关卡首通 / 独立检验，重复同局与另开同题不重复发放。会话、记录、outbox 单键事务先保存，再调用可选 `window.PorcelainHost.complete(payload)`。仅 `true` 或 `{accepted:true}` 是确认；失败、超时保留相同 completionId 和 claimIds 重试，宿主也必须按 ID 去重。无宿主可离线正常玩。

优先使用已检测版本 ≥9.46 且方法存在的 `xhs.miniTool` Storage；不适用时回退浏览器存储。原生存储写失败不偷偷改写另一存储。失败提示、奖励不发放，重试保存同一记录再投递。只操作自己的两个键族，不清空其他游戏。缓存可能被容器清理，不能保证永久持久化。

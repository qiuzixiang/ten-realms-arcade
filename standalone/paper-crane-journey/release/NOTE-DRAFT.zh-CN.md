# 把纸鹤送回庭院，我做了60关谜题

继月光、暗房、山野和染坊之后，这次折了一座安静的纸艺庭院🌿

做了一个纸鹤主题的逻辑小游戏「纸鹤归旅」。

🕊️ 点一只纸鹤，再点它能跳到的空莲叶。
🍃 横着或竖着跨过一只相邻同伴，被跨过的那只就会离开庭院。
✨ 最后不管停在哪里，只要剩下一只，就算归巢。

规则很短，但越往后，越要想清楚先后顺序。有时候眼前能跳的一步，会让另一边的小纸鹤再也回不来。

六章、60关，从4只纸鹤的小径，慢慢走进19只纸鹤的深庭。莲影、竹风、雨歇、月门……每座庭院都有不同的形状和支路。

没有倒计时，走错了可以无限撤销。提示会看你当前的局面，进度保存在当前浏览器，想停就停，下次接着想。

还有每日归巢、输入旅笺文字就能重现的庭院，以及六种不同翼纹的纸鹤图鉴。想多一点挑战，可以试着让最后一只停在✧莲心；停在别处也一样算通关。

希望这方小庭院，能陪你度过几分钟不赶时间的空隙。游玩中有建议，也欢迎留言告诉我。

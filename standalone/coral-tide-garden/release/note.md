# 珊瑚育海，慢慢解开这一局

把数字种进浅海，让每一簇珊瑚长得刚刚好🪸

玩法是：同数字上下左右连成一簇，这一簇有几格，就要填几。对角不算连接，相邻的同数字会自动合在一起。

做了 60 关、6 片海域，从 4×4 慢慢走到 6×6。不计时，支持候选笔记、撤销和提示。完成的苗圃会进入图鉴，每日苗圃从这 60 题轮换。

想给碎片时间留一点安静的思考。卡住就先数数：这一簇，是长多了，还是还差一点？

规则基于 Simon Tatham 谜题集的 Filling，主题与交互独立设计，AI 辅助开发。

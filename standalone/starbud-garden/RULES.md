# 星芽花园 · 规则契约

版本 1.0.0，slug `starbud-garden`。原型为 Simon Tatham Portable Puzzle Collection / Galaxies。参考项目 `v2/games/nebula-hatchery`，固定提交 `55cdddb75cf57c17baee80bac4121bd3be1687c6`。本任务重写纯引擎、独立区域求解器、生成器及界面；未复制上游 C 代码、图片或题面。MIT 和第三方声明保留在源目录及运行时规则面板。

棋盘以行优先索引标识格子。星核坐标为双倍整数：格心奇/奇、边心奇/偶或偶/奇、角点偶/偶。格子 `(x,y)` 关于核 `(cx,cy)` 的对应格为 `(cx-1-x,cy-1-y)`。每颗星核接触的 1/2/4 格不可分割。

玩家切换相邻格之间的正式边界。外框固定，穿过星核的边禁止修改。按未被边界阻隔的正交连接作全盘连通分量；每区必须恰含一个完整星核、以该核 180° 对称、没有区内悬空边界，才算有效。所有区域有效才判胜。非对称、不完整、多核、无核、仅对角连接均不算胜利。边界撤销恢复所有格子和笔记。

对称笔记成对添加/删除；不允许出界或覆盖星核接触格。笔记不参与区域或胜利判断。非法操作返回原状态，不增加历史。撤销重放全部剩余合法动作，重开创建新 runId，但保留此前已验证首通图鉴。完成后需重开或撤销再修改。

输入：点击格子或行/列选择器精确选格，再按四个至少 44px 的选边按钮。密集 7×7 在小屏格子可能小于 44px，以独立行列选择器保证精确操作。键盘方向键移动，Shift+方向键切边，Z 撤销。观察星核选择器显示对称位置；数字和实线辅助色弱识别。

题库版本 symmetric-growth-v1。每章 10 关：前 2 认识，中 6 组合，后 2 综合。6 章实际约束参见 release/puzzle-proof.json：格心、非矩形对称增长、边心、角点、含狭口的非矩形、综合。难度评分使用候选区域数、分支数、非矩形区域数和最大面积；属设计难度，尚无真实玩家数据。

唯一性证明使用不导入引擎、不读取答案的独立 oracle：从星核必占格枚举全部正交连通、180° 对称、避开其他核的区域，再精确覆盖棋盘及全部星核，求解至第二解或穷尽。只保留唯一且未截断的题。旋转、镜像归一化去重。2×2 的全部不重叠核配置另以边界子集穷举交叉验证。

固定教程 `starbud-garden-tutorial-v1` 是 3×3 五核题，同一 renderer 绘制初态、一次合法右边操作、引擎判胜完成态。首次可跳过，随时重看，Esc 关闭，焦点恢复，背景锁滚，换卡归零滚动。

私有命名空间 `mini-polish:starbud-garden:v1:`。存档仅信任合法动作重放；首通凭据也需重放判胜，不相信 completed 布尔值。完成 ID 为 runId + ':complete'，奖励 ID 为固定关卡首通键。先成功持久化再向可选 `window.starbudHost.onComplete(event)` 投递；此为网站集成回调，不是小红书 Native API。宿主必须按 rewardClaimId 去重，失败保留 outbox。

小红书版本 ≥9.46.0 优先官方 Storage JS API；低版本/普通浏览器降级 localStorage，所有读写异常处理。原生读取故障时停止初始化以避免覆盖已有进度。浏览器写入失败可继续玩但明确提示。仅本机存储，无云同步。API 采用 2026-09-10 在线能力文档，旧 1.6.0 包中的桥接接口差异以在线文档为准。

每日题按设备本地日期从 60 关轮换，共享主线进度；不承诺无限新题。提示有对称说明和明确标注的答案边，无计时、最少步或最优分数宣称。

# 星芽花园，给星光一处花园

状态：本地文案，尚未发布笔记。小工具 V1.0.0 已提交，当前审核中；通过后再挂载。

围绕一颗颗星核，慢慢画出属于它们的花园。每片花园只留一颗星核，格子要连在一起，转过半圈，形状仍然重合。🌱

《星芽花园》做了 60 关、6 个章节：从格心星核出发，逐步遇见边心、角点和需要绕弯思考的形状。每道题都经过独立求解验证，只有一个分区答案。

先点格子，再用上下左右按钮画边。不计时，可以撤销、做成对笔记；卡住时先观察对称位置，也可以查看一条答案边。解开一局，就在星园图鉴里留下一朵花。每日星圃从这 60 关中循环选题。

玩法原型来自 Simon Tatham 谜题集的 Galaxies，主题、题库与交互独立设计，AI 辅助开发。

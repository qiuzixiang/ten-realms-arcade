# 《雾窗显影》规则契约

版本 1.0.0，slug `mistwood-album`。原型 Pattern / Nonogram（数织）。原游戏只读来源 `v2/games/mist-photo-studio`，源仓库提交 `374d2eee951c8f6aa0bbc829e9cceaa127596b7c`。规则参考 <https://www.chiark.greenend.org.uk/~sgtatham/puzzles/doc/pattern.html>。来源许可证 MIT，详见 LICENSE / THIRD_PARTY.md。

## 规则真值

坐标为从左到右、从上到下的 0 基行列；格索引 `row * width + column`。`UNKNOWN=0`、`FILLED=1`、`EXCLUDED=2`。标 × 是明确留白，空白格仍未知。

线索是连续填格段的正整数数组，空数组显示 0。每段顺序固定，相邻段之间至少一个非填格。排除格不属于填段；没有对角邻接规则。所有格必须明确，再按全部行列重新提取连续段并与线索逐项一致，才判定完成。主题、提示、照片颜色、成就、缓存标志不参与完成判定。

`apply` 是不可变纯函数，接受界内整数索引与合法三态；越界、畸形网格、非法值、重复写同值均返回原引用，不计步。界面再次点同工具已标格是一个显式擦除动作。行列选择器只移动选中位置；大按钮写所选工具，不自动循环。

撤销恢复上一次落笔前的格值，不回扣累计落笔、历史提示次数；不会撤销已经获得的照片/印记。不设失败锁定。重开保留题面但生成新 runId，清空当前格与操作记录。提示不会减生命或扣照片。

## 题库与证明

60 张独立手绘点阵：暗房初光 10、窗台生长 10、雾巷散步 10、林间来信 10、潮汐手札 10、夜航归档 10。前两章 5×5，后四章 7×7。题面未通过重命名、旋转、镜像充数；测试计算八种对称变换规范形，全部不同。

每张图案推导出行列线索。独立审计器只接收宽高和线索，逐行枚举 2^width 位掩码，以列的连续段自动机剪枝，搜索上限 2；只有 count=1 且 exhausted=true 才声称唯一。所有 60 张满足。另穷举全部 512 种 3×3 二值照片，核对两套求解器的解数；包含多解与无解反例，防止“只找一解”伪证明。

章学习重点依次为：整条与零线索、长段重叠、多段分隔、交叉传播、边界收紧、综合验证。它们构成尺寸和推理学习路径；不宣称每相邻关的主观难度严格单调。主线全自由开放。每日用本地 YYYY-MM-DD 确定题库中的一张，允许复拍，不是无限生成器。

## 主题映射

| 规则概念 | 暗房元素 | 视觉与反馈 | 不变含义 |
| --- | --- | --- | --- |
| 填格 | 显影留下的银盐 | 深绿实体格与角标 | 属于连续填段 |
| 排除 | 留白相纸 | 浅底上的 × | 明确非填格 |
| 未知 | 尚未决定的底片 | 无符号空格 | 不满足“全部确定” |
| 行列线索 | 底片边缘的曝光编号 | 横向/纵向有序数字 | 段长与间隔约束 |
| 完成 | 照片入册 | 去掉棋盘线、彩色像素相纸与文字故事 | 引擎重新判定之后展示 |
| 进度 | 六本相册与独立印记 | 已显影缩略图、复拍记录 | 非惩罚性收藏 |

玩家是小暗房的守夜人，核心动作是“确定一格、显影一格”。胡桃木、墨绿与暖灯体现暗房；相纸托盘负责承载数字与底片。动画仅短淡入，减少动态设置移除全部非必要过渡。无强制声音。

## 提示、教程与可访问性

提示仅从题面与当前三态候选计算：先定位一条线；展开后解释合法排列数、固定分段或重叠位置；可按需要落一笔。局部或全局矛盾只给解释，绝不随意擦一格冒充正确纠错。没有直接线索推理时，尝试某格相反状态，若整个交叉约束无解，明确解释其反证。测试为 rows 属性安装抛错 getter，证明提示不读取内置照片答案。

教程固定 `candle` 首关：初始全未知；与玩家同源 apply 在第一个 # 格显影；完整合法答案由引擎判定。构建生成 3 张 SVG 与 truth.json；测试逐格重算并比对 SVG。首进自动、跳过、完整三卡、重看、Escape、焦点锁定与恢复。模态内部滚动，图片 contain。

320×720、390×844 与 1280×720 核心棋盘和主要操作整体一屏。7×7 小格配永久可见的 44px 行列选择和落笔按钮，不依赖页面缩放。键盘支持焦点、方向与工具快捷键。状态同时有实块 / × / 空白区分。

## 持久化与奖励

键前缀 `mini-polish:mistwood-album:v1:`，`state` 为游戏记录，`tutorial:v1` 为独立教程已读。当前局、完成记录都携带 runId 与完整 set/undo/hint 日志，恢复重放验证；伪造缓存 grid/completed/claims 无法独立产生通关。

completionId=`mistwood-album:complete:<runId>`。首次照片 claim=`mistwood-album:photo:<levelId>`；未展开具体推理的独立印记=`mistwood-album:independent:<levelId>`；每日首次=`mistwood-album:daily:<YYYY-MM-DD>`。每种 claim 只授予一次，复拍可补独立印记，不重复首通奖励。浏览器本地保存，不是云端账号系统。

完成 payload 严格为 `{schemaVersion:1,gameId,levelId,mode,runId,completionId,rewardClaims,metrics,completedAt}`。先持久化，再可选宿主回调；无宿主仍正常通关。抛错、无确认、写入失败都保留稳定 ID；异步回调不覆盖其间新的棋局。

小工具返回相册/暗房，不外跳。`npm test`、`npm run build` 与 `npm run qa:browser` 为专属验证入口；结果及未覆盖设备见 QA.md。

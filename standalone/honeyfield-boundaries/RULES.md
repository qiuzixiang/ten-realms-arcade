# 蜜田巡界规则契约 1.0

左上角原点，n×n方格。内部横边 h:y:x（y行边界，x列）、纵边 v:y:x（y行，x列边界）。边值0未知、1墙、2明确无墙。固定外框始终墙，不可编辑。相邻两格共享一个键。对角不连通。每次真实改变计一次编辑；非法或相同值操作原子无效。

格内线索为四面墙数，包括外框。null代表缺失，0是有效线索。未知与无墙都可通行；无需填满无墙笔记。完成须同时满足：每个可通行连通区恰好K格、全部显示线索精确匹配、每道内部墙分隔不同连通区；区域数由n²/K导出。区可折角，不要求矩形、蜂王或额外人口。

探索过程中出现未围合、数字过多、区域容量不符只是诊断；可撤销、重做、擦除和重开。提示先定位格、再解释、再落实一条事实；第三级落实标为练习。示范同样练习，不发首通。普通前两级提示不修改答案或奖励。所有提示事实绑定同版本题面和唯一性证明；用户已有错误边优先建议擦除，不依错误假设继续推导。

判胜引擎使用边表示、并查集求连通与内墙一致性。独立oracle不读取内置答案、不调用引擎，枚举所有连通K格集合，按各格内部邻居数4-线索筛选，再做完整精确覆盖，首解后继续排除第二解。任何截断题不收录。60题全部穷尽且唯一；不是最优操作路线证明。

生成器hf-gen-1固定seed7112026，逐题保存seed、参数、线索、答案、推理链与证明。无猜测链先用数字饱和、明确通路容量、完整可通行区推理，再用连通K格田形候选的共同边推理；它可涉及多格，不能等同于每位玩家均觉得简单。章节难度依据盘面与线索/推理组合，未经真实玩家难度研究。

前三章维持4×4/K4。在全部117种完整分区中，D4去重22种，只有14种全线索题可唯一确定。每章10题使用10种不同田形；章节之间允许同田形但不同约束，并非60种不同田形。前三章通过0–2、3–6、6–8处去线索推进；按“分区+线索”整体进行D4去重，60题无对称重复题面。5×5、6×6继续扩展。

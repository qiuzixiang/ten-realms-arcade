# 规则与实现契约

规则参考 Simon Tatham Portable Puzzle Collection 的 Rect / Shikaku：
https://www.chiark.greenend.org.uk/~sgtatham/puzzles/doc/rect.html

可信仓库来源：`v2/games/dream-hotel/logic.mjs`，固定提交 `55cdddb75cf57c17baee80bac4121bd3be1687c6`。已读取来源引擎并确认该文件相对固定提交无差异。上游帮助页本次网络请求超时，未声称成功重新联网核对；规则真值按固定版本纯引擎与本地许可证冻结。新引擎独立实现，不拷贝来源中的计步评级或依赖旧 UI。

## 不变量

棋盘为 n×n（n=3…6）方格，每个线索具有格坐标和正整数面积。每个正式房间是格轴对齐矩形，恰好包含一个线索，面积等于线索。房间必须在界内且互不重叠；全部格恰被覆盖时完成。装饰、提示、候选与动画不参与胜负。

点击两个对角格、或拖动，只设置预览。确认合法矩形后原子追加房间；非法操作不写入状态和历史。清房需先选择房内格再点清除，覆盖操作不会静默删除已有房间。每个房间都有实线边界，候选有虚线边界，陈设只画在不含数字的格子。

撤销重放操作历史；重开创建新 run，不删除历史成就。方向键移动键盘焦点，Enter/Space 选格。1×1 房间通过同一格点两次选择。候选为临时笔记，重开/换题/刷新清空，最多30个。

## 关卡与教程真值

独立 oracle 遍历全部可能矩形并逐格精确覆盖搜索，找到第二解即拒绝；不用内置答案判断唯一性。所有60关及教程唯一。题面与答案布局均做旋转、镜像的八重标准化去重，不能只移动数字重复同一解布局。

6章各10关；每章前2关为初识，中段练习，末2关综合。按候选余量、搜索分支和节点数筛选并逐章查看题面图，难度曲线仍待真实玩家检验。每关 ID `chapter-XX-level-YY`，seed 固定；证明记录在 `release/level-proof.json`，候选及边缘指标在 `release/level-review.json`。

教程 ID `dream-isle-hotel-tutorial-v1`。固定4×4题，三张 SVG 分别来自空状态、使用正式 place 操作后的第一间房、完整合法解；测试复算且逐字比对 renderer 输出。首次可跳过、可重看、焦点回到触发按钮，独立教程存储键不会重置成就。

提示优先解释唯一候选；需要完整解辅助时明确说“答案辅助”。查看提示即标记该 run 为辅助，用户确认后才落房。若已有房阻挡唯一解，提示说明清除/撤销，不直接篡改玩家状态。

## 存储和奖励

存档前缀 `mini-polish:dream-isle-hotel:v1:`。恢复时重新执行历史并验证房间，成就记录必须真正重放到完成，不信任 completed 布尔值。损坏条目丢弃，仍合法的条目保留；从不调用 localStorage.clear。

每章十关完成解锁一种陈设。无提示完成授予独立解题徽章。每日题由本地 `YYYY-MM-DD`、`hotel-v1` 的稳定 hash 选择，模式隔离；跨日需从首页重新进入，正在玩的昨日题保留自己的日期身份。

完成事件：`{schemaVersion,gameId,levelId,mode,runId,completionId,rewardClaims,metrics,completedAt}`。先保存成就、收据及 outbox，再可选调用同页 `window.dreamIsleHost(payload)`；返回严格 true 视为该 completionId 已确认，异常/无宿主保留原ID重试。宿主按 claim ID 去重。独立解题改进保留旧待投递事件，重复完成同一奖励不会追加事件。宿主不可用不影响本地完成；本地存储不可用显示无法保存提示，仍可玩，不发送未持久化事件。

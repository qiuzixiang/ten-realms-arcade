# 笔记标题

把帐篷搭进一页山野手账

# 笔记正文

如果能把一天的嘈杂，折成一片安静的草甸。

做了一个纸景风格的逻辑小游戏「云野露营」：每棵树需要一顶帐篷，行列数字要刚刚好，帐篷之间还要留一点空地——连斜角也不能碰。

从晨露草甸到星夜营地，再走到云海。六章、60 关，前面慢慢认识规则，后面要把整片营地一起想。还有每日一题和口令决定的十站旅途，来自另外 120 道经过验证的题面。

没有倒计时，提示不扣风景奖励。每章走完，就把一张风景收进手账。忙的时候停下来也没关系，进度会保存在当前浏览器。

操作很轻：先选格子，再点放帐或标空。手机小格也准备了方向按钮，可以一步一步精确选。

希望它能成为一小段，留给自己的山野时间。

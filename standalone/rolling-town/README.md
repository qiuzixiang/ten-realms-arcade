# 滚滚小镇

手机竖屏优先的独立 3D 滚动收集游戏。书桌、庭院、街区三个区域，每区 216 件物品，36 种收藏、6 款球心、三区评价、自由收集和 3 分钟挑战。本机自动存档，没有账号、广告、付费和运行时外网依赖。

在本目录执行：

```sh
npm run build
npm test
npm run serve
```

打开 http://localhost:4188/dist/xhs/ 游玩最终平台包。源码入口为 http://localhost:4188/ 。桌面使用 WASD／方向键；手机拖动下方摇杆，松手停下。主线没有强制倒计时，三分钟挑战在三区完成后解锁。

上传文件为 `dist/rolling-town-xhs.zip`，512×512 图标为 `dist/icon.png`。ZIP 根目录是入口、外置经典脚本、样式及引擎许可；不要上传源码目录或 qa.html。`release/` 包含三张介绍图及笔记文案。

`qa.html` 是独立验收页：使用真实移动、碰撞、收集规则自动走完整个场景，显示收集数、评价和绘制次数，不修改正式游戏存档，不随平台 ZIP 发布。

体积按收集物件累计，半径取立方根；渲染和碰撞共享同一成长值。地图采用尺寸分层布局，各区自动移动验收均能收齐 216 件。球面最多保留 76 件附着模型，已收集记录与体积不会因此丢失。场景和球面模型使用实例化合批；持续低帧率时降到 1 倍分辨率并关闭实时阴影。

存档命名空间 `rolling-town:v1`。恢复时重放收集顺序重新计算体积，避免损坏数据生成非法尺寸；收藏、最高区域评价、外观与当前旅程独立保存。离开页面或进入后台时暂停并保存。本地存储不可用时允许继续游玩并提示无法保存。

本次仅新增独立目录，未修改其他小游戏与根项目未提交的更改。具体实测结果、发布阻塞和限制分别见 QA.md、PUBLISH.md。

# 标题
把整个小镇滚成一颗球，好解压

# 正文
用 AI 辅助开发了一个手机 3D 收集小游戏：《滚滚小镇》。

从一颗小球开始，把纽扣、茶杯、玩具一点点黏上来。等自己长大，刚才还推不动的大物件，也能一起滚走。

拖动下方摇杆就能走，松手就停，镜头自动跟随。主线没有倒计时，可以慢慢逛阳光书桌、午后庭院和奶油街区。

36 种图鉴收藏、6 款球心配色，还有尺寸成长、收集数量和金色收藏三个区域目标。完成三区后，可以自由收集，也能试试 3 分钟挑战。

玩法灵感来自《块魂》Katamari Damacy，采用原创程序化模型、界面与合成音效，是非官方改编作品。代码与调试由 Codex 辅助完成。

点开笔记挂载的《滚滚小镇》，从第一颗纽扣开始吧。

# 标题
把整个小镇滚成一颗球，好解压

# 正文
做了一个可以在手机上玩的 3D 收集小游戏：《滚滚小镇》。

从一颗小球开始，把纽扣、茶杯、玩具一点点黏上来。等自己长大，刚才还推不动的大物件，也能一起滚走了。

喜欢这种不用赶时间的小游戏：拖动下方摇杆就能走，松手就停，镜头会自动跟着你。

阳光书桌、午后庭院、奶油街区，三段旅程慢慢逛。还有 36 种图鉴收藏、6 款球心配色，以及每个区域的探索目标。主线玩完也能继续自由收集，或者试试 3 分钟挑战。

点开笔记挂载的《滚滚小镇》，从第一颗纽扣开始吧。

玩法灵感来自《块魂》Katamari Damacy。这是使用原创美术制作的非官方小游戏。

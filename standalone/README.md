# 独立游戏合集

27 款成品游戏，保留各游戏源码、玩法说明、测试及许可信息。

[在线游玩](https://qiuzixiang.github.io/ten-realms-arcade/standalone/)

网页离线 ZIP 由构建生成，可在合集下载；这些下载不代表小红书平台审核或发布状态。部分模块游戏需通过本地 HTTP 服务运行。

```sh
node scripts/standalone.mjs install
npm test
npm run build
```

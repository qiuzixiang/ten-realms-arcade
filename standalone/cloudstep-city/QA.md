# 本地验收

## 已验证

- build → test → audit → qa:browser。纯 Node 构建与测试，不依赖共享根项目；浏览器依赖见 README。
- 60/60 题经独立逐格 oracle 搜索至第二解确认唯一，结果与声明答案一致；完整题面旋转/镜像去重；六章各十题。
- 四方向索引与反转、缺失线索、错误行列与线索、未完成、合法输入、非法原子操作、固定格、候选、撤销重放。
- 三张教程同一真实题面：初态、合法动作、合法完成态；SVG 每格值、方向和图像加载检查。
- 存档通过动作重放恢复；损坏 JSON、损坏动作与虚假完成记录回退。奖励按首胜/无提示首次分级去重；重复完成、不同 run 相同成绩不重复发奖；宿主失败保留同一 completionId；持久化失败不发送。
- Chrome 桌面浏览器模拟 320×720、390×844、1280×720、399/400/401×720、759/760/761×720。所有页面刷新后均注入顶部 44px、底部 34px 安全区。5×5 格子至少 44px，棋盘无水平溢出，工具栏位于底部安全区上方。
- 每个视口走首次完整教程、候选→撤销、合法落子、刷新恢复、通关、重开再次通关、奖励去重。另有触摸模拟检查教程跳过/重看/Esc/焦点恢复、提示取消/确认、收藏分页、每日入口和损坏存档恢复。
- HTTP 运行 dist/xhs，注入 script-src self、connect-src none、worker-src none、frame-src none 等受限 CSP；浏览器运行无脚本错误或站外请求。
- ZIP 根入口与 CRC、JS 被禁 API/新语法扫描、HTML 资源相对引用、CSS 基线检查、平台原版体积审计。最终体积以 DELIVERY.json 为准，低于 2MiB 项目目标。
- 已肉眼检查手机玩法、教程、桌面 5×5、通关与封面截图。一次发现带安全区时桌面 5×5 工具栏越界，已缩小行高与页头间距，并以完整矩阵复验。

## 证据

`release/browser-report.json` 包含逐视口实际布局值；`release/level-proof.json` 为固定种子与排列求解节点；`release/tutorial-truth.json` 为教程状态链。11 个 Node 测试包含独立 oracle 与去重校验。截图文件是构建产物的真实浏览器输出，不是玩法草图。

## 未覆盖与交付状态

没有实体 iOS Safari、Android Chrome、小红书容器、Chrome 61/Android 8.1 的设备环境；相应兼容性与性能未实测。页面没有软键盘输入，不涉及键盘遮挡表单，但未验证真实移动浏览器动态地址栏。现代 Chrome 的通过不等同于旧 WebView 或平台审核通过。

当前仅为本地可试玩版本；未进行独立人工终审或外部玩家难度试用，因此不标记平台发布 ready。60 题的数学唯一性不等于经过人类难度标定。提示为全盘枚举排除，不冒充细粒度人类推理链。上游在线帮助页请求超时，来源核对以固定本地规则代码为准；上传前还需复核实时平台规范。

未改共享根、来源游戏、其他独立游戏；未 commit、push、上传、创建平台草稿或发布。

## 1.0.1 终检修复

最后一步与奖励结算改为单次持久化，旧版完整局面缺记录时启动重放并幂等补结算。宿主拿到完成 payload 的副本，不能修改内部 outbox。每日局内日期取已保存的 session key，跨午夜不改本局题面日期。教程与其他弹窗同时避开顶部/底部安全区，保持内部滚动；重复无提示通关文案不再宣称获得新星。

11 项规则测试通过，9 个视口和触摸流程复验通过；新增浏览器异常中断恢复、二次刷新去重、存储配额失败和弹窗安全区边界断言通过。此轮为开发者自检，不等同于独立人工终审或实体设备测试。

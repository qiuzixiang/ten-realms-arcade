# 1.0.1 开发者终检记录

范围：自己的 standalone/cloudstep-city。开发者自检，不声称独立人工审查。

| 问题 | 修复 | 回归证据 |
| --- | --- | --- |
| 最后动作先保存、奖励后保存，中间中断可能形成完整局面但没有完成记录 | 完成动作、结算与 outbox 一次持久化；启动时重放旧完整局面并补结算 | Node recover 测试；浏览器植入只有动作的旧存档，首页恢复 1/60，二次刷新仍只有 2 个 claim 和 1 条 outbox |
| 宿主回调可修改内部待投递对象，污染失败重试的数据 | 向宿主传递 JSON 副本，内部 completionId 保持稳定 | 故意修改 ID 和奖励数组；失败保留原 payload，成功仍能确认删除 |
| 弹窗只按视口高度限制，没有独立考虑容器安全区 | 遮罩预留安全区，弹窗最大高度使用剩余空间，内容内部滚动 | 9 视口顶部44/底部34的弹窗几何断言；教程截图肉眼核对 |
| 重复通关文案仍声称获得筑城星 | 改为客观的无提示完成描述，奖励逻辑仍按 claim 去重 | 完成/重开/再完成浏览器路径及既有奖励去重测试 |
| 每日局面跨午夜时标题可能显示新日期 | 标题读取当前 daily session key 日期 | 静态核对题面、存档 key 和显示日期使用同一局标识 |

验收：npm run build → npm test（11项）→ npm run audit → npm run qa:browser（9视口 + 触摸 + 异常恢复/配额失败）。目录/ZIP 原版体积审计无警告，CRC通过。真实浏览器截图重新生成。

保留边界：独立人工审查、外部玩家难度试用、实体 iOS/Android、小红书容器与 Chrome 61 未覆盖；未上传发布。

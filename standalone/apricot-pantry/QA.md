## 规则与内容

- `node scripts/generate-levels.mjs`：3×3 完整遍历 181,440 个可达盘面，最大整段点击距离 24；4×4 用逐层双向搜索证明第 33–48 关的最短距离，输出 48 关。第 33–40 关距离依次为 1–8，第 41–48 关依次为 9、9、12、12、15、15、16、19。

- 第 3、19、44 关均有实际题面和路线；第 44 关前两排保持归位，最后两排进行交接。教程主线两步与补充长段示例均由规则引擎复算。
- `python3 scripts/package.py`：生成的 `dist/apricot-pantry-offline.zip` 为 22,180 字节，无远程资源，含本地入口和许可；压缩包低于 2 MiB。
- `python3 scripts/build-xhs.py`：生成的 `dist/apricot-pantry-xhs.zip` 为 20,768 字节，SHA-256 为 `aa000c42b2a8a53b5b741fdf0dfd60d70da503ebdca83242d552b367c33a6300`。按平台提供的 `minitool-zip-builder-1.7.0.skill` 审计目录与 ZIP，均为 6 文件、0 警告。在线容器文档更新于 2026-09-22，确认 Chrome 61 基线和 9.46+ Storage API。
- `node tests.mjs` 覆盖新版 Storage API 的旧浏览器存档迁移和原生存档优先；仓库根目录 `npm test` 通过，验证了 380 个文件；`git diff --check` 通过。

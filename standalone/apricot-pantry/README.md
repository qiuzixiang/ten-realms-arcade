# 杏橘收纳所

独立的 Fifteen 主题小游戏。48 关、6 章；第 1–32 关为 3×3，第 33–48 关为 4×4。点击与空位同行或同列的罐子，使中间整段依次滑移，一次点击计一步。

## 运行

直接打开 `index.html` 即可离线游玩；页面使用本地 classic 脚本、CSS 和 SVG，无 CDN。也可在本目录运行 `python3 -m http.server 4173`，打开 `http://localhost:4173/`。

## 生成与验证

```sh
node scripts/generate-levels.mjs
node tests.mjs
python3 scripts/package.py
python3 scripts/build-xhs.py
```

生成器遍历全部 181,440 个可达 3×3 状态，以“整段点击＝一条边”选出并证明前 32 关的最短距离。后 16 关由 4×4 逐层双向搜索证明最短距离并保存最短参考路线；第 33–40 关依次为 1–8 步，第 41–48 关为 9、9、12、12、15、15、16、19 步。`tests.mjs` 用另一套滑移实现、独立 3×3 状态图和 4×4 搜索复核题库与教程。离线包输出到 `dist/apricot-pantry-offline.zip`，不含开发脚本。

手机上按住格子显示真实受影响路径，松开提交；拖出棋盘取消。键盘方向键移动格子焦点，Enter 提交。撤销和重做按完整滑运恢复。提示第三级会把本局标为练习，练习局不解锁首通或个人最佳。

首页的继续入口会选择实际可玩的首个未完成关卡；全部完成后转到货架供复玩。“今日复盘”从已完成关卡按本地日期轮换；没有完成关卡时固定练习第 1 关。它是有限题库轮换，不设断签惩罚。

存档键前缀为 `mini-polish:apricot-pantry:v1:`。小红书客户端 9.46+ 使用容器 Storage API，旧版和普通浏览器使用浏览器存储；首次进入新版客户端会验证并迁移旧存档。恢复时会重放当前局动作和个人最佳的完整通关动作，不信任单独的“完成”布尔值。新版会验证并保留旧版 4×4 通关记录；题面已更换的关卡保留通关与解锁，但个人最佳须在新版题面重新取得，旧版未完成局保存在存档中。存储不可用时本局仍可玩，页面会提示进度无法保存。

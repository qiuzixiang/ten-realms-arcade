# 朱陶阶庭的规则与边界

给 N×N 的每个格子填 1–N。每行和每列各有每个数字一次；没有数独宫、对角条件或相邻差一条件。主线没有预填数。

显示的 `<`、`>` 是严格大小关系。横向 a 为左格；纵向 a 为上格，上 < 下画 ∧，上 > 下画 ∨。尖端总朝较小数字。未显示的相邻边没有额外约束；严格递增也不一定逐个加一，只有包含 N 个不同数字的 N 长链才占满 1–N。

空格用 0 保存，但 0 不参与大小或重复判定。只有两端都填了数，才显示刻印冲突。完整填满、每行列无重复、所有显示关系成立，才判胜；判胜不对比参考答案。

选格不填数。填写模式写正式数字；笔记模式只标候选，不能在已有正式数字上标候选。擦除、覆盖、笔记和自动候选都可撤销。自动候选只按当前已填数字与直接相邻刻印排除，不能理解为所有候选都可延伸成完整解。

提示分三层：关注位置→按顺序显示候选删除与具体依据→可证明的一步数值填写。提示不读取参考答案，先诊断重复、刻印违反、空候选或行列缺数可放。完整推理演示由空盘推导，明确标练习，练习不发首通陶砖；正式使用提示可以获砖。

数字冲突加下划线，关系冲突加虚线与 !；状态栏有文字。刻印固定不可编辑，密集的小符号之外，提供逐条 ≥44px 的「读刻印」入口。5/6阶可通过选行键和大格键准确选位置，再用数字盘填写。320px六阶格体约37px，不把它宣称44px命中；替代格键与数字键实测约88px宽。

所有60题按独立完整行排列搜索证明只有一个解，搜索器不读取参考答案、不导入游戏引擎、没有超时或节点截断。游戏推理器只做关系域传播、已确定数的行列排除和唯一位置，60题都能由空盘解完；逐步证明保存在 release/level-proofs.json。唯一性与无需猜测分别报告，不声称操作序列唯一或步数最优。

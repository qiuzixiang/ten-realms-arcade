# 把四季染进布里，我做了72关谜题

继月光、暗房和山野之后，这次开了一间小小的染坊🌿

做了一个东方织物风的颜色解谜小游戏「四季染旅」。

🎨 从布面的左上角开始，选一碟颜色，让相连的布格一起换色。
🧵 只有上下左右相接的同色布格，才会被接进染区。
✨ 在步数预算内，把整匹布染成同一种颜色，就算合幅。

看着染色慢慢铺开很舒服，但想少走几步，得先看看远处的颜色。

六章、72关，从4×4的掌心小幅，慢慢走到10×10的四时长卷。胭脂、松烟、栀子、靛青……每种颜色都有自己的纹样，也能看着图形来分辨。

没有倒计时，提示和撤销不扣星；超过预算也可以继续练习。进度保存在当前浏览器，想停就停，下次接着染。

还有每日配色、可以输入种子的自由工坊。染好的主线布样会收进收藏册，把走过的四季留在一页页布册里。

希望这间小染坊，能装下你几分钟安静的时间。

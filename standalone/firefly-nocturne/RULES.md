# 萤庭夜游 · 规则合同

游戏 ID `firefly-nocturne`；原型 Light Up / Akari；60 题、六章，题库版本 `garden-gen-1`。行列从 0 计数，正式灯位键为 `row:column`。

棋盘 `.` 是可放灯石径，`#` 是无数字墙，`0`–`4` 是数字墙。两类墙都挡光。灯照亮自身和上下左右直到墙或边界的所有石径，光可穿过叉号。两盏灯不得在无遮挡的同一行或列相望。数字只统计上下左右紧邻的灯，0 与无数字墙语义不同。

萤灯和叉号互斥。萤灯可放在已亮石径，即使临时造成互照；再次落灯可收起。先清除叉号才能在该格放灯。未亮格可加叉，已亮格不能新加叉；已有叉号即使后来被照亮仍可清除。叉号只作笔记，因叉号导致的数字候选不足是当前笔记矛盾，不是题面无解。墙格、越界和未知操作都不改变状态。

所有白格已亮、无互照、每处数字相邻灯数准确且题面至少有一块白格时完成。只满足某个数字、只让大部分石径见光或仅匹配内置答案都不算完成。撤销恢复完整灯与笔记状态，不扣分。提示分规则、相关区域、可证明一步；提示次数仅作个人记录。

题面由 `generate-campaign.mjs` 固定种子生成并静态保存于 `levels.mjs`。`solver.mjs` 使用连续行列段建模，不读取关卡自带答案；完整搜索确认 60 题各只有一个解。生成脚本 `--check` 验证可复现，`campaign-tests.mjs` 还用独立逐格射线穷举交叉核对小盘。

存档仅使用 `mini-polish:firefly-nocturne:v1:` 前缀，教程已读独立保存。恢复时重新验证灯位、叉号和胜利记录。首通事件包含稳定 `runId`、`completionId` 和 `claimId`；事件先保存到本地 outbox，再通过 `mini-game:complete` 通知可选宿主。同一关的首通奖励 ID 固定，不因刷新或重复通关叠加。

键盘：棋盘中方向键移动，Enter/空格落灯，M 加减记号，Z 撤销。手机密盘先选择分区，再在 3×3 精确面板操作；面板与整盘使用同一状态。所有功能离线运行，不请求网络资源。

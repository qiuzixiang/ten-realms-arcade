## 规则与工程

- 23 项专项测试通过；其中判线测试包含 283 组原版指令解释结果，计分覆盖 5–36 的长度总和。
- 覆盖原版随机数、开局五颗、四向通路、非法操作不改变状态、主动消除不补球、交叉计分、按顺序补球、自动消除不加分并重试槽位、末格消除与满盘判断顺序。
- 覆盖合法历史重放、错误存档恢复、存储不可用、个人成绩去重、独立 HTML、平台 ZIP 内容、生成目录边界。
- 根项目测试与根构建通过；没有提交或推送。
- 原版 EXE 只做静态读取与纯规则指令解释；没有进行完整 Win32 程序并排操作。来源与核对边界见 RULES.md。

## 小红书上传包

依据上传页提供的官方 [minitool-zip-builder 1.6.0](https://fe-static.xhscdn.com/mini-tool/20260831163932/minitool-zip-builder-1.6.0.skill) 的六份相关规范逐项检查（未使用 JSBridge，因此无原生 API 适配需求）。

- ZIP 根目录只有 `index.html` 与 `app.js`。外置经典脚本，无模块、内联脚本、行内事件、eval、iframe、网络请求或外部资源。
- 运行时代码按 ES2017 编写；移除了可选链、对象展开、新版数组 API 等唯一依赖路径。音效与随机种子增强有能力检测。
- 棋盘使用比例盒与显式 Grid 轨道；Flex 间距做行为检测与 margin 回退；使用 grid-gap、传统颜色、普通焦点样式和视口高度回退；支持容器安全区变量与真机 env。
- SVG 与 CSS 原创图形完全随包提供，最大内嵌 Base64 只有小图标；没有图片库、数据库、媒体下载、WebGL 或后台线程。
- 官方 `audit_artifact.py` 审计产物目录与最终 ZIP 均为 `PASS: 2 file(s), 0 warning(s)`。此脚本负责体积门禁，脚本与资源约束另由本项目测试及人工核对。
- Python zipfile CRC 检验通过，解压文件与 `dist/xhs/` 逐字节一致。ZIP 19,975 字节，独立 HTML 56,863 字节，512 × 512 PNG 图标 45,412 字节。

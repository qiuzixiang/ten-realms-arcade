# Color Linez v1.21 规则契约

本实现以存档中 WINLINEZ.EXE v1.21 为准，不混用 Color Lines / Lines 98 的其他变体。来源、哈希与作者见 THIRD_PARTY_NOTICES.md。

## 已核实的状态与行为

- 棋盘 9 × 9，以 `y * 9 + x` 编号；空白 0，颜色 1–7。四邻域移动，沿空格通路寻路；斜向只用于判线，不能作为移动步。
- 初始化：生成三色队列，再执行 **5 次补球槽位**（`0x4114be–0x4114d9`），初始得分 0。极罕见的初始化自动成线也按下述自动补球逻辑处理，不人为重排。
- 任意移动成功后检查落点的横、竖、两条对角线；至少 5 颗同色连续为有效线。匹配成功一次清除所涉球，玩家可以接着移动，不消耗出球队列。
- 分数 `10 + 2 × (N−5)²`（`0x410bc6–0x410be3`）。单线 5 / 6 / 7 / 8 / 9 连分别 10 / 12 / 18 / 28 / 42。多线交叉，N 是各有效线长度之和，交点计入每条线；实际球只清一次。两条五连相交：清除 9 颗，得 60 分。
- 没有主动消除时执行三次补球槽位（`0x411daa–0x411db5`）。每个槽位在按行排列的空格中随机选一格，放队首颜色、队列前移，并随机生成一个新队尾。
- 每放入一颗，立即检查新球成线。自动成线会清除、增加该色消除统计，**不增加分数**，并再次执行当前槽位，直到一颗新球留下（`0x410b19–0x410bb9`）。因此单回合可能实际出现超过 3 颗新球，预告也可能前移超过 3 位。
- 没有空格时补球返回；在三个补球槽位处理后判定棋盘填满才结束。最后一格的自动消除优先于结束判断。
- 随机数保留原版 LCG：`seed = seed * 0x41c64e6d + 0x3039`（32 位溢出），取高位的 15 位后模范围（`0x410144–0x410170`）。相同 seed / 操作序列可重放。
- 原版初始 Handicap 皇冠分数 **100**（`0x4116bd–0x411709`）；必须严格超过。超过不终止游戏。当前版以本机已保存最佳更新下一局目标。
- 预告可开关，只显示颜色，不预告位置。不提供悔棋、提示、消除道具、连击奖励、关卡、倒计时或失败复活。

## v1.21 兼容细节

原版判线在落点两侧各最多检查 7 格（`0x41080f`、`0x410860`）。本实现保留这个边界，并以原版指令解释结果建立回归样本。正常合法局面不会预存八连再从端点补第九颗；此规则主要影响人工构造的状态。

寻路使用到起点的最短距离，逆向回溯采用上、左、下、右顺序，与原版路线选择一致。动画用时属于呈现层，不参与回合或补球判定。

## 手机呈现与原版的边界

- 原版彩球 → 原创通透玻璃珠，保留 7 类；同时提供可关闭的几何纹样。
- 国王 / 挑战者 → 皇冠目标进度条，超越目标后继续刷分。
- 桌面点球点空位 → 触屏点选；长按放大选格只影响输入精度。9×9 密集棋格使用完整格命中，不扩大重叠点击区；普通工具按钮至少 44 CSS px。
- 自动续局保存 seed 与合法操作记录，恢复时重放，不信任存档中注入的棋盘和分数。此项是移动端新增便利功能，未改变正在进行的局面、随机序列与得分。
- 正式局没有“通关”。三卡教程为元素、合法移动、真实五连消除；不能把消除示例称为整局通关。
- 分数榜为本机个人前十局，每局 ID 去重；无服务器、跨设备同步或外部奖励。

## 验证依据

对归档二进制只进行静态读取与纯规则指令解释，未启动 Windows 可执行程序。`tests/reference-fixtures.json` 包含来源哈希、283 组判线结果与 5–36 的计分结果。解释器按 `0x4107ec` 与 `0x410bc6` 的 i386 指令计算，不调用本项目判线实现。

原版未在当前 macOS 环境中进行完整 Win32 界面并排实机回放；不得将静态核验表述成已进行原版实机对照。浏览器界面与平台兼容验证另见 QA.md。

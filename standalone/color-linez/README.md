# 五子连珠

将 Color Linez v1.21（1999）的经典规则重制为手机优先的复古小游戏。界面采用原创 Windows 98 风格窗口、棋盘和立体彩球；没有运行时第三方依赖、CDN、账户、广告或付费功能。

## 运行与交付

在本目录执行 `npm test`、`npm run build`。再运行 `npm run serve`，打开 http://localhost:4186/dist/ 。

- `dist/index.html`：完全独立 HTML，样式、脚本与图形全部内嵌，适合浏览器直接打开。
- `dist/glass-linez-xhs.zip`：小红书上传包，根目录为 `index.html`、`app.js`；脚本外置且为 ES2017 经典脚本，符合平台禁止内联 / module 脚本的要求。不要把单文件网页自行压成上传包。
- `dist/xhs/`：ZIP 解压后的同等内容，用于本地检查平台版本。
- `dist/icon.png`：512 × 512 原创图标，供平台基础信息表单单独选择。
- `dist/web/`：同一游戏的分模块静态网页。
- `dist/build-info.json`：版本、体积与依赖信息。

上传文件已经本地打包不代表平台审核通过。

平台填写：名称「五子连珠」，简介「复古彩球连线，重温童年回忆」，版本 `1.0.0`。游戏仅使用本机存档，不使用相册、摄像头、麦克风或网络。

打包依据为 2026-09-06 上传入口提供的官方 `minitool-zip-builder 1.6.0`。平台只接受 ZIP，最大 10 MB；图标接受 PNG / JPG / JPEG，最大 5 MB。详细核验与未实测范围见 [QA.md](QA.md)。

本目录 `dist/` 和仓库 `dist/standalone/color-linez/` 是构建拥有的生成目录，请勿放置手动编辑文件。构建仅可替换这两个指定路径。其他合集和小游戏的文件及存档不迁移。

## 操作与数据

点珠子，再点空格移动；触屏长按放大选格；桌面使用方向键与 Enter / 空格。初次三卡教学可跳过、重看。设置支持音效、出球预告和辨色纹样。

合法操作后立即保存；动画中退出也能恢复完整回合。保存命名空间为 `glass-linez:`。本机最高分与同一局记录去重保存，浏览器存储不可用时仍能游玩并给出提示。

## 核对范围

核心行为已从指定 v1.21 归档核对，包括开局 5 颗、七色、四向通路、交叉计分、顺序补球、自动消除不加分并重试槽位、预告队列及原版随机数。详情见 RULES.md 与 THIRD_PARTY_NOTICES.md。

美术采用原创 SVG 立体彩球和 CSS Windows 98 风格棋盘；没有拷贝原版位图或音乐。保留规则的游戏改编，应在发布介绍里标注出处。

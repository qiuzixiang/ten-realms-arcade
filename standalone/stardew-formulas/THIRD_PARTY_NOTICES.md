# 来源与许可

规则参考 Simon Tatham's Portable Puzzle Collection 的 Keen（算笼拉丁），原始规则并非本项目原创。上游文档也介绍其与 KenKen / Inshi No Heya 的关系。

- 上游：https://www.chiark.greenend.org.uk/~sgtatham/puzzles/doc/keen.html
- 可追溯快照：ebnbin/puzzles `5a9e1795a3324e0f6433b79fbe31cbd9b12048a3`。
- 2026-09-20 从本仓库已有 Git 对象核对 `doc-zh/keen.html`、`vendor/sgtpuzzles/keen.c` 及 `vendor/sgtpuzzles/LICENCE`。完整上游声明见 `UPSTREAM-LICENSE`，中文参考项目许可见 `REFERENCE-LICENSE`，运行包中亦保留于 `licenses.json`。
- 旧游戏参考目录：`小游戏-five-release/v4/games/quantum-apothecary`。规划读取提交 `55cdddb75cf57c17baee80bac4121bd3be1687c6`；开发工作树基于主项目 `374d2ee`。未直接复用旧游戏引擎；新引擎、独立 oracle、界面和题库均在本目录实现。
- 原创部分沿用项目 MIT License，见 `LICENSE`。本包无外部字体、图库或第三方运行库。瓶子与图标为 CSS / SVG 绘制，没有生成式位图。
- 平台 1.6.0 规范归档仅作开发参考，不进入游戏运行包。来源地址为技能中记录的官方静态地址；原始来源、版本和核验限制见 `platform/README.md`。

本名称指游戏主题中的“星露配方”，未使用任何其他商业游戏的角色、美术、音乐或世界观。

# 彩砾壁画馆 · tessera-mural-studio

本地独立版：6章60关，Mosaic 规则。矿物蓝计数彩片、灰白底片与灰泥接缝构成修复工作台，完成作品以实际玩家格态收藏，并可切换松绿、赭黄装饰彩釉。

## 运行与复现

本目录是完整独立项目，不改共享注册表。Node 18+、Python 3 和 zip 命令即可完成规则与打包流程，无 npm 安装步骤。ZIP按排序文件清单与固定UTC时间戳构建，可逐字节复现。

```sh
npm run generate
npm run build
npm test
node scripts/compatibility.cjs
python3 -m http.server 8080 --directory dist/xhs
```

访问本机 http://localhost:8080。生产入口为 `dist/xhs/index.html`，离线候选为 `dist/tessera-mural-studio-xhs.zip`。

浏览器验收用现有 Playwright 和 Chrome，不自动下载安装。可设置 `PLAYWRIGHT_PATH` 指向 Playwright 包、`CHROMIUM_PATH` 指向 Chrome 可执行文件，再运行 `node scripts/browser.cjs` 和 `node scripts/edge-browser.cjs`。截图封面用 `node scripts/media.cjs` 重建。已提交版本可用 `python3 scripts/verify-clean.py --audit-script /绝对路径/audit_artifact.py` 做干净归档复验；归档工具需Python 3.12+，审计脚本使用本地1.7.0规范归档。默认路径来自本开发环境，其他机器应配置上述变量。

## 规则与操作

数字统计受边界裁切的3×3九宫，包含数字格自身。角落4格，非角边6格，中央9格。数字格也能是彩片。null 无数字，0 要求该邻域没有彩片。彩片计数，底片不计，斜纹未定。所有格明确且所有数字准确才胜利；不附加连通或相邻限制，也不对比隐藏参考画。

彩片循环：未定→彩片→底片→未定；底片循环反向。清除直接回未定，清除空格不记动作。默认逐格点击、不拖涂；查看邻域是独立模式，点击只选格。键盘方向键移焦，Enter彩片循环、Space底片循环、Delete/Backspace清除、U撤销。完成后输入冻结，撤销可恢复修复。支持重做、确认重开。

提示先标出相关数字，再解释余量或两个邻域相减，最后由玩家确认填一格。相减时两枚数字标为A/B，公共未定格用实线、差集用虚线，并展示实际余量算式。提示只读取当前格态和显示线索，不读取证明答案。无可解释结论时明确提醒检查早先误片。提示不扣首通收藏章，收藏作品记录提示次数。

## 六卷题库

1. 第一枚彩砾：4×4，满/空邻域与含自身；全部可单数字推理完成。
2. 边框里的数字：4×5到5×5，边界与剩余候选；全部可单数字推理完成。
3. 重叠的窗：5×5到6×5，必须使用重叠邻域相减。
4. 断纹接续：6×6，间接约束与无数字格。
5. 长幅织画：6×7到6×8，多层重叠与显式底片。
6. 壁画开馆：6×6到6×8，综合修复。

同尺寸按记录的相减步骤数排列，较大的题随后出现。这是推理证据支持的课程排序，不是玩家实测难度。60道独立主线均通过二进制方程搜索：找到第一解后继续搜索并穷尽，恰好一个解。`release/proofs.json` 包含线索哈希、独立解证书、穷尽结果、推理轨迹、对称去重签名。没有镜像、旋转或换色凑题。每日题为60天有限轮换，日期按UTC+8，不宣称无限生成。

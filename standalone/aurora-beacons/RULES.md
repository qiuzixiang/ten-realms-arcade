# 规则与版本合同 v1

规则参考 Magnets（Simon Tatham's Portable Puzzle Collection），原始创意 Janko，由 James Harvey 贡献。参考旧项目 v2/games/aurora-magnet-lab 的规则契约；计划来源提交 55cdddb75cf57c17baee80bac4121bd3be1687c6，本次 worktree 基线 374d2eee951c8f6aa0bbc829e9cceaa127596b7c。此实现为重新编写，未复制上游 C 或美术资源。

坐标是行优先的一维索引 r*w+c，每格恰属一个正交双格槽。按上到下或左到右顺序，状态 1 为正负、-1 为负正、0 为中性；null 为未填。所有槽明确赋值、所有给定行列正负配额同时相等、同极无正交接触，才算胜利。对角相同允许。缺失线索 null 不施加约束；0 是有效零配额。

赋值错误可保留用于推理，但不会结算。非法槽/非法状态/无变化动作原子 no-op。笔记只附加星标，不参与候选求解或判胜；撤销恢复赋值与笔记。提示不填写棋盘：先指出配额或邻接冲突，再解释局部唯一候选，最后允许用户主动揭示一格唯一解。

## 题库

生成器 v1，初始 seed 20260922，60 关，每章 10 关。前 2 关概念练习，中 6 关组合推理，后 2 关综合。章节从双极、方向、中性、配额、邻接到综合；所有规则从开始有效，章节是练习重点，并非规则开关。

尺寸为 4×4、4×6、6×6；逐章目标删去 0、1、2、5、8、12 条线索。章节内按独立求解器分支和节点排序。第三章中性练习刻意回落到局部推理，再进入大盘组合。当前难度为启发式排序，尚无真实玩家留存或大样本难度数据。

独立求解器最多搜索两解；找到第二解即淘汰，只有首解后穷尽搜索才承诺唯一。所有题面与完整线索答案模式分别按 D4 旋转/镜像及正负互换归一化；不靠换方向/删线索复用答案凑数。release/proofs.json 为每题节点、分支和深度摘要，测试重新求解而非信任摘要。

## 存档与事件

私有前缀 mini-polish:aurora-beacons:v1:，save 保存当前动作历史和已完成关卡的合法动作证据。读档重新执行动作并判胜，不信任完成布尔值。教程键独立为 aurora-beacons-tutorial-v1。只写自己键，不调用 localStorage.clear。

runId 在新局生成，completionId 为 aurora-beacons:<runId>，rewardClaimId 为 aurora-beacons:first:<levelId>。每关首次完成先存记录和 outbox，再尝试可选 window.AuroraHost.complete(payload)。宿主必须同步返回 true 才确认收件，抛错/缺失/未确认保留相同 ID 下次保存重试，宿主亦需按 ID 去重。重复完成不再奖励。存储失败不调用宿主，并显示未保存状态。

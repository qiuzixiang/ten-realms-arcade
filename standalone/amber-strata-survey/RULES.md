# 琥珀勘探队规则契约

`amber-strata-survey` 是独立的 Mines / Minesweeper 改编。坐标按行优先排列：`index = y × width + x`，`x` 和 `y` 从零开始。每个安全格的数字为相邻八格的危险格数量，不含自身；边角只计算棋盘内的格。危险集合由固定关卡给出，数字始终重新计算。

覆盖格可探测或插旗。旗记只是玩家笔记，不改变危险集合、首扫状态或胜利条件。探测 0 格会展开相连的 0 与边界数字，已插旗格会阻挡展开。首次真正探测若碰到危险格，会以 `seed` 和索引决定的位置移动该一颗危险格，保持总量并重算数字；只保证点击格安全，不保证周围安全或全局无猜。之后触雷进入失败态，普通输入停止，玩家可以撤销或重开。撤销恢复前一步棋盘、危险集合、动作与探测数，错误刻痕仅作为诊断保留。

合并探测只对已揭开的正数格生效：其周围旗数必须恰好等于读数，才会打开全部未插旗邻格。旗位置错误可能触发真正的危险格。界面先预览格子、说明风险，玩家再确认。旗数相等不表示已证明安全。覆盖格、旗、已开格和触发格均有不同形状。所有非危险格揭开即胜利，危险格无需全部插旗。无效输入是原子 no-op，不计步。

主线 60 关、六章各十关，从每题可见的指定「勘测口」开始。点击开始按钮才执行真实首次探测；关卡证书仅覆盖该起点与由公开信息推出的后续步骤。自由练习可任选首次探测格，仍享有首扫安全迁移，但没有全程无猜认证。两种模式的完成记录相互隔离。

证明器只接收公开尺寸、总危险数、当前覆盖/旗记/已开状态及已开读数。它依次使用单数字、候选集合差集、公开总数和有节点上限的穷尽枚举；超限返回未知，不视为证书。60 道题的固定起点都可由该证明器走到真实引擎的胜利态，轨迹可重放。玩家提示另将所有旗记暂当未知，以免把未经验证的玩家笔记当成真值；若可证明某面旗所在格安全，先提示玩家拔旗。

存档只保存关卡 ID、模式、run ID、提示数和操作轨迹；加载时由固定关卡完整重放，拒绝非法操作、伪造完成和主线绕过起点。完成事件带稳定的 `completionId`、`rewardClaimId`、`seed` 和生成器版本。完成与待投递事件先保存在本游戏私有命名空间，再通知可选宿主。浏览器和小工具缓存可能被清理，不能视为云端备份。

操作数统计成功的探测、旗记与合并探测；提示次数另记，不增加操作数。任务簿按模式显示该关最少操作数，同操作数时保留提示较少的记录。这是个人记录，不宣称数学最优。

规则参考 Simon Tatham's Portable Puzzle Collection 与 `ebnbin/puzzles@5a9e1795a3324e0f6433b79fbe31cbd9b12048a3` 的 Mines；本游戏的主题、界面与关卡设计独立制作。许可及来源见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

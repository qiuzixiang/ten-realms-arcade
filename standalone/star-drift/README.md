# 星际漂流 · Star Drift

一款独立浏览器惯性解谜游戏：决定方向，点燃推进器，借助舱壁与引力锚回收整片航区的星核。

- **48 关、6 个章节**：从八个手工教学关开始，逐步掌握借墙转向、引力停泊、危险余程和回收顺序。
- **真实最短步数**：所有剧情关由 BFS 证明；最深挑战需 17 次推进。题面并非只靠旋转、镜像或改名增加数量。
- **每日航线**：同一日期对应同一张可解星图。
- **自由远航**：轻航、巡游、深潜三种节奏；输入同一航图编号与难度可以重返同题。生成次数有限，必要时使用明确标记的精选备用题，不承诺无限唯一关卡。
- **自动保存与成长**：逐关解锁、最高星级、个人最佳和星图碎片保存在本浏览器；不会读取或清空原合集进度。
- **辅助工具**：完整航段预览、无限撤销、下一步提示、三张真实棋盘教程、键盘与触摸支持。

3 星表示未用提示且达到真实最短步数，2 星表示独立通关，使用提示后通关得 1 星。撤销与航段预览不扣星。

## 本地运行

无需安装第三方依赖。开发和测试使用现代 Node.js；本地静态服务示例使用 Python 3。

在本目录运行：

```sh
npm test
npm run serve
```

然后打开 `http://localhost:4173/`。若从整个仓库根目录启动服务，入口为 `http://localhost:4173/standalone/star-drift/`。ES Modules 与 Web Worker 需要通过 HTTP 访问，请勿双击 HTML 使用 `file://`。

## 独立构建

```sh
npm run build
python3 -m http.server 4173 --directory dist
```

产物位于本目录的 `dist/`，可以整体复制到任意静态网站目录。运行时仅依赖产物内部相对路径，不依赖原合集、Node 服务或第三方 CDN。构建不会向外部平台发布。

整个仓库执行 `npm run build` 时也会输出 `dist/standalone/star-drift/`。原合集 V1 的预缓存和 Service Worker 明确绕过 `/standalone/`；独立游戏没有注册新 Service Worker，也不承诺离线运行。

**输出目录规则：** 本目录 `dist/` 与仓库根目录 `dist/standalone/star-drift/` 是此构建脚本拥有的生成物，会在重新构建时替换。构建脚本拒绝其他删除目标；请勿在这两个生成目录保存手工编辑文件。独立测试也会重建本目录 `dist/` 以检查运行资源。

## 操作

| 操作 | 输入 |
| --- | --- |
| 向上 / 右 / 下 / 左 | 方向键，或 W / D / S / A |
| 左上 / 右上 / 左下 / 右下 | Q / E / Z / C |
| 八方向小键盘 | 7 / 8 / 9 / 4 / 6 / 1 / 2 / 3 |
| 撤销 / 提示 / 重开 | U / H / R |
| 重看教程 | ?，或右上角飞行指南 |
| 触摸 | 在棋盘上朝目标方向滑动，或轻点方向按钮 |

能源芯不会刹车。即使已收齐，当前航段上还有暗雷仍会失败；出发前请检查整条路线。舱壁无害，引力锚与归航起点会立即停船。斜向移动只检查下一个目标格。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `index.html`、`styles.css`、`app.mjs` | 页面、布局、交互、音效与教程 |
| `core.mjs` | 与界面无关的纯规则、撤销、BFS 求解器 |
| `levels.mjs`、`generate.mjs` | 48 关数据、章节、每日题与种子远航 |
| `renderer.mjs` | 游戏和教程共用的 SVG 棋盘 |
| `storage.mjs` | 独立命名空间、合法操作回放、成长与幂等结算 |
| `worker.mjs` | 后台求解与生成，避免阻塞主要交互 |
| `assets/` | 背景与图标 |
| `tests/` | 规则、关卡、存档、教程和生产资源集成测试 |
| `tools/generate-levels.mjs` | 可复现的剧情题面筛选与证明报告 |
| `tools/build.mjs` | 仅复制运行必要资源的独立静态构建 |
| `RULES.md`、`THIRD_PARTY_NOTICES.md`、`ART.md` | 规则契约、来源许可与美术记录 |

本目录是独立浏览器游戏，**不是微信小游戏或微信小程序移植**。它不接入原合集的奖励宿主、微信桥接或私有存档。

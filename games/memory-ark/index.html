规则与来源

如何唤醒方舟

  1. 滚动核心每次只能向上、下、左、右的相邻地格滚动 90°，不能越过 4×4 阵列边界。
  2. 交换滚动完成后，新的底面与落脚地格交换“有符印 / 无符印”状态；离开的地格不变。
  3. 收集开局六个表面为空，六枚符印散落在地面。让六枚符印同时分别位于六个表面即获胜。
  4. 精进所有局面都由已解状态严格逆向构造，保证可解。步数越少，航迹越利落。
